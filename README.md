### 2. Smart Resume Screener

An AI-powered resume screening platform that analyzes resumes, extracts skills, matches candidates with job requirements, and helps recruiters make faster hiring decisions.

- Upload and parse PDF resumes.
- Extract and normalize candidate skills.
- Create and manage job descriptions.
- Generate AI-based resume-to-job matching scores.
- Analyze matched skills, missing skills, experience, and education.
- Present candidate insights and recommendations.

**Tech:** React · Node.js · Express.js · MongoDB · Google Gemini
